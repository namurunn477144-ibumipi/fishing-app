# いぶみー フィッシング

いぶちゃん・みーちゃんの つりゲーム。せとうちかい・かわ・にほんかい・たいへいよう・ほっかいどうで、ほんものの さかな 63しゅるいを つって ずかんを うめよう。

- つりかた：うきづり／ルアー（リールを ぐるぐる）／エギング（しゃくって しずめる）
- つった さかなは もちかえる・うる・にがす。おかねで どうぐや ふねの きっぷを かえる
- しゅんの さかなは たかく うれる。よるに よく つれる さかなも いる
- かんたんモード：いとが きれない
- パートナー：シャワーズ・ゼニガメ・コダック・ヤドン・ニョロゾ・パルシェン・マリルリ・アシレーヌ
- さかなの えは すべて SVG で かいた オリジナル
